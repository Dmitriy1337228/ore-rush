# AGENTS.md — инструкции для агента

## Командный режим (включается ТОЛЬКО по явному указанию игрока)
Триггеры: слэш-команда `/team <задача>` или прямая фраза игрока («собери команду: …», «режим команды», «командой …»). В этом случае следуй плейбуку `.kilo/command/team.md`: тимлид — основной агент (GLM-5.3-Flash), архитектор `team-architect`, разработчик `team-dev`, ревьювер `team-reviewer` (все GLM-5.3-Flash), тестировщик `team-tester`, разведчик `team-scout` и менеджер памяти `team-memory` (все DeepSeek V4 Flash 0731; провайдер всюду openrouter, модели зафиксированы в .kilo/agent/team-*.md). Координация — через общую доску (board_post/board_read) с зеркалом для игрока в .kilo/team-board.md, долговременная память команды — .kilo/team-memory.md. Во всех остальных случаях — обычный одиночный режим: команду не поднимать и работу не делегировать.
