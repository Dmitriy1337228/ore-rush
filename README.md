# Рудная лихорадка: Тайна алмазных недр

Браузерный idle-кликер про шахтёра, который добывает руду всё глубже и глубже — от угольных пластов до алмазных недр. Кликай по рудному блоку, покупай улучшения, плати за спуск и открывай новые ярусы шахты. Играть можно прямо в браузере: **[dmitriy1337228.github.io/ore-rush](https://dmitriy1337228.github.io/ore-rush/)**

## Что за игра

- **12 тиров руды**: уголь → медь → железо → серебро → золото → аметист → изумруд → рубин → сапфир → платина → уранит → алмаз. Спуск на новый ярус оплачивается рудой текущего тира, цена фиксируется при входе — прокачка никогда не «отбрасывает» прогресс
- **26 улучшений в двух вкладках**: кликовая цепочка (кирки, кувалда, гидропресс, плазменный резак, расщепитель), машинная лестница от шахтёра до сферы Дайсона, множители и усиления (криты, золотые жилы, синергия). Мультипокупка x1/x10/x100/МАКС
- **Мутации блока**: раз в несколько минут блок может стать радужным (x10 добыча), замороженным, взрывным или заряженным
- **Ежедневные награды**: серия дней открывает 7 наград по циклу — ускорения, накопитель, критический импульс, бесплатное улучшение, мощный буст, золотая жила. Пропуск дня сбрасывает серию
- **Престиж**: 1T алмазов за забег → звёзды, каждая даёт +10% ко всему доходу
- **Фоновая добыча**: до 24 часов пассивного дохода между сессиями (склад и фонарь увеличивают ставку)
- **Адаптивный интерфейс**: ландшафт и портрет, от десктопа до телефона 375px

## Технологии

- **Phaser 4** + чистый JavaScript (ESM), сборка **Vite**
- Пиксель-арт ассеты сгенерированы SpriteCook, фоны локаций — локальный ComfyUI (SDXL), звук — Stable Audio; шрифт Monocraft (OFL-1.1)
- Весь игровой код изолирован от платформы за заглушкой `sdk-stub.js` — при релизе на Яндекс Играх содержимое одного файла заменяется на реальный SDK, код игры не меняется

## Запуск

```bash
npm ci        # установка зависимостей
npm run dev   # dev-сервер на http://localhost:5174
npm run build # прод-сборка в dist/
```

В репозитории также лежат автопроверки: `node scripts/verify-economy.mjs` и соседние `verify-*` гоняют экономику и UI через Playwright, `scripts/ui-review.mjs` снимает скриншоты всех экранов и аудит вёрстки. Вся внутренняя документация проекта — в [CONTEXT.md](CONTEXT.md), дизайн-документ — в [GAME_DESIGN.md](GAME_DESIGN.md).

Деплой: push в `master` автоматически собирает и публикует сайт на GitHub Pages (`.github/workflows/deploy.yml`).
