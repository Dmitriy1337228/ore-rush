## 8. Захватывают ли скриншот-гейты DOM (0.5)

**Да.** Оба гейта снимают страницу целиком, а не канвас:

- `scripts/ui-check.mjs:109` — `page.screenshot({ path: file })` (аннотированный PNG);
- `scripts/ui-review.mjs:170` — `page.screenshot({ path: ... })` (golden-снимки).

`canvas.toDataURL` нигде не используется. Следствия:

- DOM-слой попадёт в скриншоты `ui:check`/`ui-review` автоматически — отдельный «скриншот страницы»
  для golden (этап 5, шаг 5.3) не нужен как блокер; tolerant-diff всё равно вводится для стабильности.
- Golden остаётся зелёным, пока DOM включается только флагом (`?dom=1`): сценарий `21_craft_open`
  без флага рисует Phaser-версию.
- DOM-аудит (этап 1) должен сам мерить `getBoundingClientRect`, т.к. `uiAudit.js` знает только
  display list — это и есть работа `scripts/ui-check-dom.mjs`.

## 9. Черновик правил для `AGENTS.md` (шаг 5.5; применять только после G3 = go)

> **DOM-слой (`src/dom/`)**: вёрстка — только токены/переменные (`src/dom/tokens.css`, генерируется
> `npm run dom:tokens`), никаких голых чисел размеров; проверки — `npm run ui:tokens:css` и
> `npm run ui:check:dom`; полный UI-прогон = `npm run ui:check` + `npm run ui:check:dom`.
