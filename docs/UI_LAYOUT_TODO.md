## 4. Сжигание долга baseline (`tests/ui-check/baseline.json`, ~1100 нарушений на старте)
Распределение на момент внедрения: MIN-FONT 476, TOUCH-TARGET 296, OVERLAP 290, TEXT-COVERED 40.
Больше всего на телефоне-ландшафте 844×390 (417), далее портрет 360–412 (≈450 суммарно).
- [ ] **OVERLAP (приоритет):** карточка «Снаряжение» при активном бое (описание «урон робо-руки…»
      залезает на кнопки, иконки на кнопки покупки); значения ресурсов с иконкой самородка
      в портрете (`#K`/`#B` × `copper_nugget`/`emerald_nugget`); подсказка мастерской поверх
      иконок компонентов (портрет); кнопка закрытия × `map_board`; текст «Ты вырубился!»
      × тело модалки; «За текущий забег…»/«клик: … · крит» × кнопки в настройках при больших числах.
- [ ] **TEXT-COVERED:** вкладки «Оборудование/Усиления» и подписи шапки закрыты полупрозрачными
      слоями обучения/хит-зонами — проверить порядок отрисовки.
- [ ] **MIN-FONT:** портрет и 844×390 — кегли 9–14 px при FIT-масштабе 0.5–0.6 дают <8 CSS px.
      Решение: портретная сетка с большими кеглями (`_adaptiveScale`) и пересмотр ландшафта
      для низких экранов (отдельная раскладка/масштаб для высоты < 480 px).
- [ ] **TOUCH-TARGET:** кнопки покупки в рядах и мастерской (31–33 CSS px высотой) — увеличить
      hit-area до ≥ 40 CSS px (можно без увеличения картинки: расширить интерактивную зону).
- После каждой пачки исправлений: `npm run ui:check -- --update-baseline` и в коммите
  указывать, на сколько уменьшился долг.
