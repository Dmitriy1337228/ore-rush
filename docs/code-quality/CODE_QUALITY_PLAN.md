4. **Рефакторинг = ноль изменений поведения.** Допустимы: пути и имена файлов, комментарии (включая JSDoc), конфиги ESLint, npm-алиасы, новые скрипты-гарды, механические `catch {}`, удаление мёртвого кода (по правилам M4). Всё прочее — недопустимо: при необходимости такого изменения этап считается сбойным (0.5).
5. Единственные «решатели» в ходе работы — D-пункты (раздел 1), таблица 0.4 и DoD. Игрока в ходе работы не спрашивать.
6. Отчёт этапа: что сделано, результаты команд DoD, отклонения, `Skills: <файлы>` (если применялись) — запись в журнал.

### 0.4. Автоматические решения (вместо остановок)

| Развилка | Правило |
|---|---|
| Константа/каталог данных без любого комментария | Однострочный `/** <имя>: что это и зачем */` — готовая формула, без вопроса |
| Спорное место «что писать в JSDoc» | По образцам существующих комментариев проекта (D1); не опрос |
| Мёртвый экспорт, используемый только `verify-*` | Не удалять без grep по `scripts/` и `tests/`; используется — оставляется с JSDoc |
| Неиспользуемый параметр в сигнатуре | Правка сигнатуры отдельным коммитом с проверкой вызывающих |
| Фактические числа расходятся с вердиктом (41/33, 19/35, ≈135) | Источник истины — инвентарь этапа 0; расхождение — запись в журнал |
| `espree` не резолвится из `scripts/gates/` | Добавить точную версию `espree` devDependency той же правкой (запись в журнал) |
| В новых `.mjs`-скриптах есть DOM-глобалы вне `page.evaluate` | Расширить зону Приложения Б точным перечнем глобалов (запись в журнал) |
| Неоднозначность, не покрытая планом | Вариант с **меньшим изменением** кода и сохранением гейтов; решение — в журнал; `question` не используется |

### 0.5. Политика сбоев (аварийное завершение вместо паузы)

1. **Красный обязательный критерий внутри этапа:** до 2 попыток исправления в рамках допустимых изменений (0.1, п. 4). Не исправлено → `git revert` коммитов этапа (история не переписывается), запись в журнал.
2. **После отката — аварийное завершение:** отчёт «план не выполнен» (выполненные этапы, место сбоя, причина); ветка `chore/code-quality` остаётся для разбора, **в `master` не сливается**. Решение о продолжении — игрок новым запуском.
3. **Превышение бюджета этапа >50 %** — запись в журнал, работа продолжается; **общий жёсткий стоп — 5 дней** (правка 13): при достижении — аварийное завершение по п. 2.
4. **Правила пересмотра из вердикта (признаются аварийными выходами, а не продолжением):**
   - **Q3:** если инвентарь вскрывает детекторы, собираемые строкой динамически (не находимые grep'ом), или любой `verify:*` после пробного переноса не удаётся починить за 0.5 дня — откатить M2, вернуть вариант «`state.js` остаётся навсегда» с записью в `docs/DECISIONS.md`.
   - **Q1 (M1):** если после 1 дня работы выполнено <50 % функций — остаток вынести отдельным планом (D0 фиксируется: «JSDoc — по принятому охвату, остальное — новое предложение»), не растягивать кампанию.
5. **Нельзя «лечить проверку»:** не ослаблять `UI_RULES`/пороги гейтов, не расширять `tests/ui-check/baseline.json`, не обновлять golden и не скрывать объекты ради зелёного прогона; исключения `docs:check` — только как в Приложении А, не «до нуля».

## Приложение А. Спецификация гейта `docs:check` (правка 2, ответ 1 вердикта)

- **Скрипт:** `scripts/gates/check-jsdoc.mjs` (Node; разбор — `espree`, как в Приложении E реорганизации; если не резолвится — зафиксировать точную версию devDependency).
- **Определение экспорта:** statement `export …` (`export const/let/var/function/class/default`) и именованные `export { … }` с локальными именами — проверяются; **исключения:** `export * from …` (реэкспорт), `export { … } from …` (списки-реэкспорты), сам баррель `src/state/index.js`, `src/ui/dom/dev/**`, файлы `fixtures*`. Вне охвата целиком: `scripts/**` (в т.ч. `scripts/lib/**`).
- **Что проверяется:** у каждой экспортируемой **функции/класса** на охвате D2 — JSDoc-блок с `@param` для каждого параметра и `@returns`; **имена `@param` сверяются с фактическими параметрами** функции (иначе гейт ловит только наличие блока, а не дрейф). У констант/данных-каталогов — блок `/** … */` или примыкающий `//`-комментарий (пустые — однострочник).
- **Выход:** код ≠ 0 при пропуске или дрейфе `@param`; отчёт — список `файл:строка:символ`.
- **Скорость:** ≤ +10 % к времени полного набора гейтов.
- **Подключение:** алиас `docs:check` в `package.json`; строка в `scripts/README.md`; `--self-test` на заведомо неполных файлах (W2); упоминание в «полном наборе» `AGENTS.md` и README проекта.
