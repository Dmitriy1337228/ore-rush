- Что проверить руками на телефоне 375/390 (по правке №10 вердикта): скролл DOM-списка (вкладки «Оборудование»/«Усиления»), пакеты x1/x10/x100/МАКС и отклик ряда, статус-окна поверх списка (скрим не пропускает клики), офлайн-окно и дейли по очереди, обучение до tutorialDone на Phaser-вкладках.
- G1 (неделя DOM-пути без критики) — вернуть отложенный этап через неделю после слияния; затем решается снос Phaser-списка/статус-модалок и шаг «финальной классификации».
- Известный внешний долг: `ui:check` `l844|boss`/`d1024|boss` MIN-FONT (окружение/шрифты, воспроизводится на master) — при красном прогоне сначала точечный реплейс, не откат ветки.

**Внешний долг (не дефекты ветки):** падения/флейки `verify:settings-dom` ST8/ST1f (воспроизводились и до ветки — гонки таймингов и mount), MIN-FONT drift extreme-вьюпортов.
